# Peminjaman Barang PNP - Releases

This public repository distributes Windows installers and update metadata for the Peminjaman Barang PNP desktop application.

- Download the latest installer from the [Releases page](https://github.com/muhammadsyaiful2601/peminjaman-releases/releases).
- Release assets include the Windows setup executable and metadata used by the in-app updater.
- Application source code is maintained in a separate private repository.
